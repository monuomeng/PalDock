# 安全、隐私与质量标准

## 威胁模型与默认行为

入口包括桌面交互、IM 消息/附件、模型输出、扩展、供应商进程和本地 IPC。授权链必须绑定发起人、渠道账号、会话、项目、任务、能力和审批；外部内容及模型输出不能自行提升权限。默认关闭外部渠道、电脑操作与自动执行高风险操作；默认最小权限与受控工作目录。桌宠 UI 并不是安全边界。

必须防止：未授权消息执行命令、群聊冒充用户、跨项目会话泄漏、提示注入触发工具、附件路径穿越、任意路径访问、子进程注入、任务重放/重复提交、审批重放、日志泄密及扩展越权。

## 操作授权与数据保护

审批能力按运行时实际支持映射，不能声称不支持的审批已被强制执行。危险命令、跨目录写入、远程发送和生产操作要求显式策略与用户确认；拒绝、失联、超时默认失败关闭。shell 参数使用参数数组，避免拼接用户输入；确定路径规范化并验证边界、链接及工作区隔离。凭据使用操作系统凭据存储或等效安全组件，禁止写入配置/示例/快照/日志；敏感数据导出需明确选择。密钥只传给被授权的目标服务。

日志默认记录事件类型、关联 ID、结果和耗时，避免消息正文、终端输出及凭据；用户启用诊断时需可见范围和脱敏预览。持久化、备份与清理必须描述保存位置、权限和保留期。错误日志不得泄漏 token。默认不启用匿名遥测。

## 桌面与网络

Electron 采用 context isolation、sandbox、受控 preload 和最小 IPC；渲染页面不能直接访问 Node 或凭据。禁止加载未验证的远程代码。服务默认仅回环/受限 IPC，认证本地客户端并验证来源；不把后台管理端口暴露公网。远程消息渠道采用平台签名/认证和最小权限，使用官方事件 ID 去重。

## 测试策略

- 领域单测：状态机、并发冲突、授权、拒绝、审批时效与消息映射。
- 适配器契约：正常、错误、超时、取消、重连、版本不支持、事件重复/乱序，mock 离线运行。
- 集成：临时 SQLite、迁移/备份恢复、outbox、进程崩溃与重启；以临时 Git 仓库和 mock runtime 为默认。
- 端到端：Windows 桌面→任务→Codex adapter→事件→结果；真实模型/飞书为单独 opt-in 测试，标注费用和环境，不进入默认 CI。
- 安全：不可信消息不得越权、路径穿越、脱敏、外部账号隔离、审批重放、凭据泄露扫描。
- 质量：对协议行为版本锁定和兼容矩阵；格式、类型、静态检查、依赖审计与许可证检查随工具链落地。仅在真实执行通过时标记通过。

## 可观测性与完成标准

指标优先统计队列、任务状态、延迟、失败类别和 token（如供应商提供），清晰区分采样和真实计费；审计事件记录谁在什么时间授权了什么，不记录秘密。功能完成需有文档、测试、异常路径和恢复说明；生产级承诺需单独完成威胁建模和安全评估。
