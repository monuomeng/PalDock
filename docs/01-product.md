# 产品定义与验收

## 定位

搭档坞是一款本地优先的 AI 桌面助手和协作入口：用户可在桌面或经授权的外部渠道沟通，由协调助手组织多个有独立会话、角色与执行能力的助手，共同完成任务。桌宠是可隐藏的交互外壳，任务中心提供完整状态；桌宠关闭后的后台行为需由用户明确配置。

目标用户：在 Windows（随后 macOS）上同时使用 AI 编程工具、希望从桌面或团队消息入口委派任务的个人及小团队。首先支持中文，保留国际化接口。

## 首要场景

1. 用户在本地为受信任项目创建会话，向协调助手提出任务。
2. 协调助手创建可审阅的任务及子任务，开发助手使用 Codex 在指定工作区运行。
3. 用户在桌面查看事件、输出和所需审批；助手执行完成后展示结果及验证情况。
4. 停止、失败、重启后可追踪任务状态，安全恢复可恢复的会话；无法判定外部操作结果时明确提示，不自动重复执行。
5. 后续接入飞书，再添加 Claude Code、测试及文档助手；多个渠道按显式绑定关系访问任务。

## 主要功能

桌宠交互、托盘和设置；本地项目管理；外部/内部独立会话；助手角色与权限；任务和子任务；Codex/Claude 执行器；消息渠道适配器；审批和审计；本地数据备份；可选择的模型供应商及 Higress；基础诊断和用量统计。

## 版本范围与非目标

P0 仅验证能力；P1 在桌面完成本地端到端最小闭环；P2 引入受控飞书入口；P3 增加 Claude 和多助手；P4 再扩展桌宠与生态。见 [路线图](03-roadmap.md)。首版不承诺生产级多租户、原生手机应用（手机端先通过飞书/Telegram 使用，iOS 客户端见 ADR 0002）、全自动生产操作、绕过第三方权限或完全离线运行。

## 首版验收

- 在 Windows 本机显式选择或新建项目；桌面创建任务后可运行 Codex，看到进度、结果和可恢复的会话标识。
- 默认有限权限；审批请求真实显示并等待决定，拒绝、超时、取消可见；进程崩溃不会伪报完成。
- 停止和重启后，消息及任务记录完整可查；重复事件不会重复启动相同任务。工作区变更可由用户查看。
- 安装/数据目录、凭据位置、卸载与备份在文档中说明；无密钥进入日志和仓库。运行 smoke、契约及恢复测试。

## 状态与边界

外部消息触发任务与执行命令是独立授权；会话来源不自动授予文件和系统权限。产品自身的会话记录、Codex 原生 thread、Claude 原生 session 是不同实体；第三方 UI 是否显示不作保证。
